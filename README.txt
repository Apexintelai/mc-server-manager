MC SERVER MANAGER 7.0
=====================

Double-click "MC Server Manager.exe".
First launch: if Windows says "Windows protected your PC", click More info -> Run anyway.
It downloads Java automatically the first time.

NEW IN 7.0: phone control (Settings), custom buttons + welcome messages (Automation), console filters + chat mode, datapacks (World), export/import whole server (File menu), activity chart (Players), update checker. 38/38 feature tests pass.

NEW IN 6.0: completely new UI - server icon rail (Discord style), game-launcher banners with pixel-art worlds and a big START button, stat chips, players list, launcher-style Home cards

NEW IN 5.1: Settings page with 7 themes (Dark, Midnight, Light, Ocean, Nether, Creeper, Amethyst), accent colours, interface size, Terracotta helper for Bedrock

NEW IN 5.0
- Brand-new dark design: every control restyled, side menu per server, accent colours
- Home screen with live cards for all servers
- Pop-up notifications in the corner
- Ctrl+K quick search: jump anywhere, start/stop, back up
- Backups to any folder (USB drive, OneDrive...) - Tools > Preferences
- Keyboard shortcuts (press F1)
- Every button tested automatically

EVERYTHING ELSE
- Java (Paper, Vanilla, Purpur, Fabric, own jar) and Bedrock servers, one-click downloads + right Java
- Dashboard, console, players + history, world tools, game rules, MOTD, server icon

- Hide my IP (playit.gg / own relay), UPnP, own domain, streamer mode, crash helper, tray
